# Project Information

**Project:** Numerical Investigation of an Angle Crack in a Plate Using COMSOL Multiphysics

**Model:** `angle_crack_plate.mph`

**Solver:** COMSOL Multiphysics 6.3

**Analysis:** 2D stationary linear elastic fracture mechanics

**Benchmark:** NAFEMS R0020 angle-crack benchmark

**Parameters studied:** crack angles 90°, 67.5°, and 22.5°

**Primary outputs:** J-integral, KI/K0, KII/K0
